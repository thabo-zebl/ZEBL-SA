# 03 — Shielded Arcade: Hands-on Testnet Lab

This lab uses **testnet TAZ only**. TAZ is valueless test currency. Stop and ask a facilitator if an app asks for a seed phrase, spending key, payment, or identity document.

The arcade is split across the two days so wallet setup is not repeated during the send exercise:

1. **Day 1 (14:45–16:00):** [Install a wallet, create a Unified Address, request TAZ](03a-day1-wallet-setup.md).
2. **Day 2 (11:00–12:30):** [Send a shielded payment and verify it on a testnet explorer](03b-day2-shielded-payments.md).

Do not use Nighthawk. It no longer supports outgoing Zcash payments. Facilitators must confirm the wallet list in the [facilitator runbook](../docs/facilitator-runbook.md) the week of the workshop.
